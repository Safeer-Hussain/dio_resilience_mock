## 0.1.0

- Initial release of `dio_resilience_mock`.
- Pure Dart zero-dependency resilience and fault-injection mock engine.
- Configurable deterministic latency simulation and jitter.
- Chaos fault injection with forced status codes and failure probabilities.
- Automatic offline cache fallback for resilient GET requests.
- Comprehensive telemetry tracking metrics including request count, fault rate, and average latency.
- Seamless compatibility with Dio interceptors, adapters, and standard Dart HTTP clients.
